# DSA in Java

```
mvn test                              # run all tests
mvn -Dtest=TwoSumTest test            # run one test class
python ../scripts/new_problem.py <topic> <ClassName>
```

Topics (packages): arrays, strings, hashing, twopointers, slidingwindow, stackqueue, linkedlist, binarysearch, trees, heap, graphs, backtracking, dp, greedy

Each solution class documents approach, time and space complexity in its Javadoc.
