# GenAI / LLM Apps (Python)

Setup:

```
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Each numbered folder is one topic: a short README (goal, what to build, checklist)
plus runnable scripts. Keep experiments small and commit them often.
